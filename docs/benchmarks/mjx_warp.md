# MJX-Warp ORC Benchmark

This report is generated by `experiments/benchmark_mjx_env.py`. Compilation and first CUDA graph capture are excluded from steady-state throughput.

## Adoption status

**Do not adopt.** Best measured graph mode: `warp_staged`.

- Physics speedup: 3.732×
- Estimated total training speedup: 1.424×
- 1.5× performance gate: pass
- Capacity gate: fail
- Required-model finiteness gate: fail
- Behavioral parity gate: must also pass the CUDA-marked pytest suite before public adoption.

### Required-model behavioral failures

All nine realistic-`octahedron` Warp cases ended with non-finite observations
and 100% termination. This explicitly blocks adoption even though the abstract
three-topology workload clears the performance threshold in staged graph modes.

The total-training number is an Amdahl-law estimate using the previously measured 40.67% environment-step hot-path share. It is not an end-to-end GNN-SAC measurement.

## Focused realistic-model diagnostic

Run the seeded diagnostic before repeating the full benchmark matrix:

```bash
python -m experiments.diagnose_mjx_warp_realistic --batch-size 8 --steps 100
```

It uses equivalent saved initial states and pre-generated actions for native
MuJoCo, MJX-JAX, and all three Warp graph modes. Every Warp mode is run at base
and doubled contact/constraint capacities. The JSON identifies the first
non-finite or tolerance-divergent field and environment and records stepwise
contact/constraint high-water marks; the companion NPZ retains the full traces.
